# Scene plan: "7 verdades sobre la higiene después de los 60"

About 3,330 spoken words → **~22 minutes** at 150 wpm. Sections: intro (~1:40), Verdad 1–7 (~2:40 each),
conclusión (~1:40). Timing from the voice-over (transcribe → cues 0.1–0.3 s before the keyword).

Format: the approved flat format (`projects/7dias_sin_cenar/`, `projects/oido_memoria/`): code infographics plus real
drawings shown as push-in stills and cut-outs. `youtube-style.md` rules: picture on every beat, ≤ 6-word captions,
≤ 2 captions on screen, hook cuts every 1.5–2.5 s. No exercises → no pose sheets for movements.

Drawings (budget ~1 per 15–20 s): **sheet 0 (character design, approve first) + 2 pose sheets (12 cut-outs)
+ 8 scene sheets (32 panels) + 2 item sheets (20 items) ≈ 64 drawings**.
Files: `intro.html`, `verdad1.html` … `verdad7.html`, `conclusion.html`, shared `common.js`.

## Visual system
- **Characters:** Carmen (72, main "you" character, dry skin, calm life) and Antonio (68, active, gardener).
  First appearance of each in Verdad 7 gets the label «Dramatización»; in other sections they act as "you".
- **Progress strip** (top right): 7 drops/circles with code icons: 1 calendar, 2 "2–3", 3 thermometer, 4 soap,
  5 washcloth, 6 cream jar, 7 four-piece pie. Current ringed orange, past filled.
- **Kicker:** "VERDAD 3 · EL AGUA MUY CALIENTE" over the section's first picture (≤ 1.5 s).
- **Skin cross-section** (item B1) is the recurring mechanism device: a "brick wall" barrier (cells = bricks, lipids =
  mortar) drawn in code over it; hot water / harsh soap washes mortar out (red), cream seals it (green), water drops
  escape upward (evaporation).
- Colours: green = good habit, amber = depends, red = warning. Calm body pace (audience 60+), no flashes.
